# One by One Organizing (Client Website) 
From February to April 2024, I designed and delivered the initial version of the **One by One Organizing ** website for a real client. The project focused on creating a clean, responsive UX while aligning with the client's branding and SEO goals. <br/>
This repository documents the *design process, technical decisions, and lessons learned* from building a production website for a client.
## Project Scope
- Responsive website design for multiple platforms
- Visual branding (layout, colors, typography, imagery)
- SEO-focused structure and content optimization
- Client collaboration and iteration
---
## Platform choice <br/>
**The client wanted to be able to control what was added while still holding long-term maintainability without ongoing developer dependency. I suggested Squarespace due to its layout tools and custom code injection to deliver a responsive, SEO-conscious design aligned with the client's business goals**

---
## Development Process
**Phase 1 - Discovery & Planning**
- Gathered client requirements and goals
- Reviewed brand direction and target audience
- Planned site structure with SEO in mind

**Phase 2 - Design & Build**
- Created responsive layouts for mobile and desktop
- Selected color palette, fonts, and imagery
- Implemented SEO best practices (headings, structure, metadata)

**Phase 3 - Review & Handoff**
- Iterated based on client feedback
- Delivered a production-ready website
- Provided documentation and guidance for future updates

---

## Lessons Learned
- My first experience building a website for a **real client**
- How to translate non-technical goals into technical decisions
- Practical SEO implementation beyond theory
- The importance of clear communication and expectation-setting

---

## What I would change
- Prioritize a stronger backend/content structure earlier in the process
- Allocate more time for scalability and future updates
- Apply current technical knowledge to improve maintainability and performance

---

## Project Status
The initial version of the website was completed in April 2024. Ongoing maintenance and updates were later transitioned to another developer while I returned to full-time coursework.
